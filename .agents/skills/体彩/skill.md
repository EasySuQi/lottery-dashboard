# 超级大乐透分区冷热分析 & 选号生成器

## 触发条件

当用户提出以下任一需求时调用此 Skill：
- 分析大乐透/体彩数据
- 查询大乐透开奖号码
- 生成大乐透选号
- 大乐透冷热号分析
- 体彩号码推荐
- 提到"大乐透"、"超级大乐透"、"体彩"等关键词

> **注意**：双色球使用"福彩" Skill，两者通过关键词区分（福彩/双色球 vs 体彩/大乐透）。

## 核心能力

1. **数据获取**：从中国体育彩票官网 (sporttery.cn) API 拉取最新开奖数据
2. **前区分区**：按 01-12 / 13-24 / 25-35 三区拆分，输出各区冷热频次
3. **后区约束**：蓝球冷热划分 + 两码和值 9-17 规则校验
4. **选号生成**：基于分区热号胆码 + 连号规律 + 冷热配比生成 2 组 7+2 号码

## 与双色球（福彩）的关键差异

| 维度 | 超级大乐透 |
|------|--------|-----------|
| 前区 | 01-35 选 5 前 |
| 后区 | 01-12 选 2 后 |
| 三区划分 | 01-10 / 11-20 / 21-33 | 01-12 / 13-24 / 25-35 |
| 开奖日 | 每周一、三、六 |
| 数据源 | cwl.gov.cn | webapi.sporttery.cn |
| 推荐前区 | 7 码 | 7 码 |
| 推荐后区 | 3 码 | 2 码 |
| 后区和值范围 | 9-16 | 9-17 |

## 执行步骤

### Step 1: 获取原始数据

```bash
curl -s --connect-timeout 10 --max-time 30 \
  "https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry?gameNo=85&provinceId=0&pageSize=30&isDetails=1&pageNo=1"
```

解析返回的 JSON (`value.list` 数组)，取最近 20 期数据。
每期字段：`lotteryDrawNum`(期号), `lotteryDrawResult`(空格分隔: 前5+后2), `lotteryDrawTime`(日期)。

### Step 2: 运行分析引擎

将获取到的 20 期数据注入 `references/dlt_analyzer.js` 脚本顶部的 `draws` 数组，执行 `node` 命令。

### Step 3: 输出格式

必须包含以下四个章节：

**一、前区分区校验**
- 逐期展示近 20 期每期三区分布 (一区 01-12 / 二区 13-24 / 三区 25-35)
- 标注是否三区全覆盖（缺区标红警示）
- 输出各区热号(≥4次)、温号(2-3次)、冷号(≤1次)明细

**二、后区冷热划分 & 两码和值约束**
- 后区 01-12 频次表，分为 HOT(≥4次) / WARM(2-3次) / COLD(1次) / ICE(0次) 四级
- 列出符合"两码和值 9-17 + 非全热 + 非全冷"的两码组合
- 标注代表性搭配模式

**三、选号约束条件**
- 连号规律：近 20 期连号出现率及高频连号对
- 各区胆码候选（按频次 + 活跃度排序取前 3）
- 区间分布约束说明

**四、成品号码 (2 组)**
- 每组含 7 个前区号码 + 2 个后区号码
- 附带分区码数比 (如 3-2-2)、连号标注、冷热标签
- 后区两码和值逐一校验
- 最终汇总表格

## 关键规则（不可违反）

### 前区规则
| 规则 | 说明 |
|------|------|
| 三区定义 | 一区 01-12, 二区 13-24, 三区 25-35 |
| 全覆盖 | 每 7 码必须含三区各至少 1 码 |
| 不扎堆 | 单区最多 3 码，最少 1 码 |
| 热号主导 | 热号(HOT+WARM) ≥ 5 个 (7 码中) |
| 连号加持 | 每组至少含 1 组连号 (差=1) 或跳连 (差=2) |

### 后区规则
| 规则 | 说明 |
|------|------|
| 冷热阈值 | ≥4次=HOT, 2-3次=WARM, 1次=COLD, 0次=ICE |
| 和值范围 | 任取两码之和 ∈ [9, 17] |
| 禁止全热 | 两码不能全为 HOT |
| 禁止全冷 | 两码不能全为 COLD/ICE |
| 搭配要求 | 必须混合 ≥2 个热度等级 |

### 冷热判定阈值
| 等级 | 前区(35选5,20期) | 后区(12选2,20期) |
|------|-----------------|-----------------|
| 🔥 热号 | 出现 ≥4 次 | 出现 ≥4 次 |
| ● 温号 | 出现 2-3 次 | 出现 2-3 次 |
| ❄️ 冷号 | 出现 1 次 | 出现 1 次 |
| 🧊 极冷 | 出现 0 次 | 出现 0 次 |

> 前区理论期望 ≈ 20×5/35 ≈ 2.86 次，热≥4 合理。后区期望 ≈ 20×2/12 ≈ 3.33 次，热≥4 合理。

## 注意事项

- 数据源为 `webapi.sporttery.cn` 官方 API（国家体育总局体育彩票管理中心）
- 每次调用必须重新拉取数据，确保使用最新开奖结果
- 超级大乐透每周一、三、六开奖（开奖日 21:25）
- 输出末尾必须附免责声明：不构成投注建议，彩票为独立随机事件
- 分析结论为历史统计推演，历史频率不代表未来概率
- 大乐透前区范围较大（35 码），7 码推荐覆盖约 20% 号码池，属于合理扩选范围
