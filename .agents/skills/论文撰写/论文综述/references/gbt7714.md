# GB/T 7714-2015 参考文献著录规则速查

> 中华人民共和国国家标准《信息与文献—参考文献著录规则》(GB/T 7714-2015)
> 适用范围：所有学科中文学术论文参考文献著录

---

## 1. 文献类型标识码

| 类型 | 代码 | 类型 | 代码 |
|------|------|------|------|
| 期刊文章 | [J] | 学位论文 | [D] |
| 专著 | [M] | 会议论文集 | [C] |
| 报纸文章 | [N] | 报告 | [R] |
| 标准 | [S] | 专利 | [P] |
| 电子资源 | [EB/OL] | 其他 | [Z] |

## 2. 各类型著录格式

### 2.1 期刊文章 [J]

```
[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**中文示例**：
```
[1] 尹少淳. 美术教育中的心理调节功能研究[J]. 中国美术教育, 2018, 39(2): 4-9.
[2] 王华, 李明, 张强, 等. 青少年创作焦虑的干预研究[J]. 心理科学, 2020, 43(3): 689-696.
```

**英文示例**（姓全大写在前，名缩写在后）：
```
[3] CSIKSZENTMIHALYI M. Creativity: Flow and the psychology of discovery and invention[J]. Journal of Happiness Studies, 1996, 32(1): 41-63.
[4] EISNER E W, SMITH R A, BROWN T, et al. Artistic cognition and adolescent development[J]. Studies in Art Education, 2019, 60(4): 287-301.
```

### 2.2 专著 [M]

```
[序号] 主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

**示例**：
```
[5] 钱初熹. 美术鉴赏及其教学[M]. 北京: 人民美术出版社, 2006: 55-78.
[6] DEWEY J. Art as Experience[M]. New York: Minton, Balch & Company, 1934: 35-57.
```

### 2.3 学位论文 [D]

```
[序号] 主要责任者. 题名[D]. 学校所在地: 学校名称, 年.
```

**示例**：
```
[7] 刘明. 初中美术课堂中学生创作焦虑的质性研究[D]. 上海: 华东师范大学, 2021.
```

### 2.4 会议论文 [C]

```
[序号] 主要责任者. 题名[C]//会议录名称. 出版地: 出版者, 出版年: 起止页码.
```

### 2.5 报纸文章 [N]

```
[序号] 主要责任者. 题名[N]. 报纸名, 出版日期(版次).
```

### 2.6 电子资源 [EB/OL]

```
[序号] 主要责任者. 题名[EB/OL]. (发布日期)[引用日期]. 获取和访问路径.
```

## 3. 著录要点速查

### 3.1 责任者项

| 规则 | 说明 | 示例 |
|------|------|------|
| 不超过3人 | 全部列出 | `王华, 李明, 张强` |
| 超过3人 | 列前3人 + ", 等" | `王华, 李明, 张强, 等` |
| 英文不超过3人 | 全部列出 | `EISNER E W, SMITH R, BROWN T` |
| 英文超过3人 | 列前3人 + ", et al." | `EISNER E W, SMITH R, BROWN T, et al.` |
| 英文姓全大写 | 每个字母大写 | `DEWEY J` 而非 `Dewey J` |
| 英文名缩写 | 大写首字母 + . | `John Dewey` → `DEWEY J` |

### 3.2 题名项

- 题名必须完整照录，含副标题
- 英文文章题名：仅首词首字母大写（其余小写，专有名词除外）
- 英文期刊名：每个实词首字母大写

### 3.3 年份项

- 统一使用公元纪年，4位数字
- 中文：用全角逗号 `,` 或直接空格分隔
- 英文：用半角逗号 `, `

---

## 4. 常见错误

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 忘记页码 | 期刊论文必须标注起止页码 |
| 英文作者大小写混乱 | 姓全大写，名缩写大写+点 |
| et al 未斜体 | `et al.` 应斜体或统一风格 |
| 期号遗漏 | 有卷号一般也有期号 |
| 出版地遗漏 | 专著[M]必须标注出版地 |
