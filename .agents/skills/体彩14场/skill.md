# 足彩14场胜负彩评估引擎

## 触发条件

当用户提出以下任一需求时调用此 Skill：
- 分析足彩14场/胜负彩数据
- 查看14场开奖结果
- 评估14场胜负彩走势
- 足彩14场统计/热力分析
- 提到"足彩14场"、"胜负彩"、"14场"、"传统足彩"等关键词

> **注意**：与"体彩" Skill（超级大乐透）通过关键词区分。"体彩14场"关键词包含"14场"、"胜负彩"、"足彩"等。

## 核心能力

1. **历史数据获取**：从中国体育彩票官网 API 拉取近20期14场胜负彩开奖数据
2. **胜平负分布统计**：统计分析每期 3/1/0 结果分布、连号规律、冷热场次
3. **奖金走势分析**：一等奖、二等奖注数与金额趋势，识别"火锅奖"和"冷门期"
4. **位置热度矩阵**：14个场次位置各胜平负频次热力图，辅助判断各位置冷热度
5. **难度评估报告**：基于历史数据的综合难度评级，输出可量化的参考指标

## 与双色球/大乐透的关键差异

| 维度 | 双色球/大乐透 | 足彩14场 |
|------|-------------|----------|
| 类型 | 随机数字型 | 竞猜型（足球赛果） |
| 号码范围 | 固定号码池 | 14 场比赛各 3 种结果（3/1/0） |
| 结果空间 | 组合数学决定 | 比赛实际结果决定 |
| 分析方法 | 冷热号 + 分区 + 连号 | 胜平负分布 + 位置热度 + 奖金冷热度 |
| 选号方式 | 生成推荐号码组合 | 评估走势 + 标注风险场次 |
| 核心指标 | 频次、区间覆盖 | 3/1/0 比例、奖金波动、冷门指数 |

## 执行步骤

### Step 1: 获取历史开奖数据

```bash
curl -s --connect-timeout 10 --max-time 30 \
  "https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry?gameNo=90&provinceId=0&pageSize=30&isDetails=1&pageNo=1"
```

解析返回的 JSON (`value.list` 数组)，取最近 20 期数据。
每期字段：`lotteryDrawNum`(期号), `lotteryDrawResult`(14个空格分隔的结果: 3=胜/1=平/0=负), `lotteryDrawTime`(日期), `totalSaleAmount`(销售额), `prizeLevelList`([{一等奖},{二等奖}]), `matchList`(对阵详情)。

### Step 2: 运行分析引擎

将获取到的 20 期数据注入 `references/sfc_analyzer.js` 脚本顶部的 `draws` 数组，执行 `node` 命令。

### Step 3: 输出格式

必须包含以下五个章节：

**一、开奖结果总览**
- 近20期逐期展示 14 场胜平负结果矩阵
- 每期标注 3/1/0 计数分布
- 标注异常期（某个结果占比极端、一等奖无人中等情况）

**二、胜平负分布 & 位置热度分析**
- 整体 3/1/0 比例趋势图（各期变化曲线）
- 14 个位置各自的 3/1/0 频次热力表
- 标注每个位置的"热门结果"（最高频）和"冷门结果"（最低频）
- 高平局位置（平局≥5次的位置）标为 ⚠ 高风险

**三、奖金冷热度分析**
- 逐期一等奖注数 & 单注奖金对比表
- 标注"火锅奖"期（一等奖注数 ≥100 且单注奖金 <10万）
- 标注"冷门期"（一等奖注数 ≤5 或无人中）
- 奖金波动指数（标准差 / 均值）

**四、难度综合评估**
- 基于以下维度的综合难度评分（满分 10）：
  - 平均平局占比（平局越多越难预测）
  - 奖金波动程度（波动越大越不稳定）
  - 一等奖命中率（越低越难）
  - 位置结果分散度（同一位置 3/1/0 分布均匀 = 难预测）
- 近期走势预测：正路期 / 冷门期交替规律

**五、评估结论 & 参考建议**
- 总结近期趋势特征
- 标注高风险场次位置（历史结果分散、平局概率高的位置）
- 给出趋势性描述（不构成投注建议）

## 关键规则（不可违反）

### 结果表示
| 代码 | 含义 | 说明 |
|------|------|------|
| 3 | 主队胜 | home win |
| 1 | 平局 | draw |
| 0 | 主队负 | away win |

### 统计阈值
| 指标 | 阈值 | 说明 |
|------|------|------|
| 火锅奖 | 一等奖≥100注 且 单注<10万 | 正路结果、多数人猜中 |
| 冷门期 | 一等奖≤5注 或 无人中 | 多场爆冷、难度极高 |
| 正常期 | 其余情况 | 常规难度 |
| 高平局风险 | 单位置平局率 ≥25% (5/20) | 该位置难以判断 |
| 高确定性位置 | 单结果占比 ≥60% (12/20) | 该位置结果倾向明显 |

### 难度评分维度
| 维度 | 权重 | 计算方式 |
|------|------|---------|
| 平局比例 | 30% | 近20期平均平局数 / 14 |
| 奖金波动 | 25% | 一等奖奖金 CV 系数归一化 |
| 命中率 | 25% | 1 - (平均一等奖注数 / 理论最大) 归一化 |
| 结果分散度 | 20% | 14个位置平均熵值归一化 |

## 注意事项

- 数据源为 `webapi.sporttery.cn` 官方 API（国家体育总局体育彩票管理中心）
- 足彩14场（gameNo=90）为传统足彩胜负游戏，每期竞猜14场比赛的主胜(3)/平局(1)/客胜(0)
- 每次调用必须重新拉取数据，确保使用最新开奖结果
- 足彩14场开奖频率取决于赛事安排（通常每周 2-4 期）
- **本 Skill 不做对阵分析和球队能力评估**，仅做历史开奖数据的统计推演
- 如 API 返回的 matchList 包含完整对阵信息，可在总览中展示比赛背景
- 输出末尾必须附免责声明：不构成投注建议
- 分析结论为历史统计推演，历史频率不代表未来概率
