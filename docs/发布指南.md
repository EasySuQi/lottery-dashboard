本指南说明如何将 `docs/` 目录发布到 GitHub Pages，让任何联网的电脑都能打开三个彩票分析仪表盘。

## 二、一次性配置（只需做一次）

### 第 1 步：准备 GitHub 账号
1. 访问 https://github.com 注册或登录（若已有账号直接登录）。

### 第 2 步：生成访问令牌（Personal Access Token）
1. 登录后访问：https://github.com/settings/tokens
2. 点击 **Generate new token (classic)**
3. 填写：
   - Note：`lottery-dashboard`
   - Expiration：选一个较长周期（如 90 天或 No expiration）
   - 勾选权限：**repo**（整个 repo 勾上即可，包含 push 权限）
4. 点击 Generate，**复制生成的 token**（形如 `ghp_xxxx`，只显示一次，务必保存好）。

### 第 3 步：配置本地 git（在本机执行）

在 Claude Code 里直接粘贴下面三条命令执行，或自己在终端运行。把 `<你的名字>`、`<你的邮箱>`、`<你的token>` 替换成真实值：

```bash
git config --global user.name "<你的名字>"
git config --global user.email "<你的邮箱>"
git config --global credential.helper store
```

> `credential.helper store` 会在你第一次 push 输入 token 后，把凭证明文保存在 `~/.git-credentials`，后续推送无需再输。

### 第 4 步：创建远程仓库
1. 访问 https://github.com/new
2. Repository name 填：`lottery-dashboard`（或任意你喜欢的名字）
3. 选择 **Public**（GitHub Pages 免费版只支持公开仓库）
4. **不要**勾选 "Initialize this repository with a README"（保持空仓库）
5. 点击 Create repository。

---

## 三、首次发布（推送代码）

在 Claude Code 里告诉我「推送发布」，或自己执行以下命令。注意把 `<你的用户名>` 替换成真实 GitHub 用户名：

```bash
cd E:/AI_Works
git init
git add docs/ scripts/build_site.js .gitignore
git commit -m "彩票仪表盘站点首次发布"
git branch -M main
git remote add origin https://github.com/<你的用户名>/lottery-dashboard.git
git push -u origin main
```

> 首次 push 会提示输入用户名和密码：
> - 用户名：你的 GitHub 用户名
> - 密码：粘贴第 2 步生成的 token（不是 GitHub 登录密码）

---

## 四、开启 GitHub Pages

1. 推送成功后，打开仓库页面：https://github.com/<你的用户名>/lottery-dashboard
2. 点击 **Settings** → 左侧 **Pages**
3. **Source** 选择：**Deploy from a branch**
4. **Branch** 选择：`main` 目录选 `/docs`
5. 点击 Save

等待约 1-2 分钟，页面会显示你的站点地址：

```
https://<你的用户名>.github.io/lottery-dashboard/
```

在任意联网电脑的浏览器打开这个地址，即可看到聚合首页。

## 五、数据更新后重新发布

每次分析脚本产生新数据后，重新打包 + 推送即可更新线上站点：

```bash
cd E:/AI_Works
node scripts/build_site.js        # 重新打包，刷新 docs/ 目录
git add docs/
git commit -m "更新仪表盘数据"
git push
```

## 六、可选：让打包自动纳入分析流程

各分析脚本目前生成的是各自的 `dashboard_data.json`。若希望"跑一次分析 → 自动更新线上站点"，可把以下两步追加到 `run_daily.bat`（体彩14场）或各 agent 的收尾：

```
node E:\AI_Works\scripts\build_site.js

```

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 打开页面图表不显示 | Chart.js 走 CDN，需联网；若网络受限可本地化 chart.js |
| 推送提示 403 权限不足 | token 未勾选 `repo` 权限，或 token 已过期 |
| 页面 404 | Pages 的 Branch 目录没选 `/docs`，或推送后未等待部署完成 |
| 想改成私有仓库 | 免费 Pages 不支持私有仓库，需用 GitHub Pro 或其他托管 |

---

## 八、安全提示

- 本方案为**公开访问**，任何人拿到链接都能查看（数据为历史开奖统计，无敏感信息）。
- token 会以明文存于本地 `~/.git-credentials`，请勿泄露此文件内容。
- 若 token 泄露，立即到 GitHub Settings → Tokens 里 Revoke 并重新生成。
