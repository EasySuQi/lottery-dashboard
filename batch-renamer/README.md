# 📝 批量重命名工具

一个跨平台的桌面应用，用于批量调整文件夹中文件的命名规则。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 添加/删除前缀 | 在所有文件名前/后插入或移除指定文本 |
| 添加/删除后缀 | 在文件名与扩展名之间插入或移除指定文本 |
| 查找替换 | 将文件名中的指定文本替换为新文本 |
| 插入序号 | 按文件名顺序插入递增编号（支持自定义起始值和位数） |
| 大小写转换 | 支持全部小写、全部大写、首字母大写 |
| 预览列表 | 实时显示"原文件名 → 新文件名"对照表 |
| 撤销操作 | 支持撤销最近一次批量重命名 |

## 🚀 运行

```bash
# 1. 安装依赖
npm install

# 2. 启动应用
npm start
```

## 📦 构建分发

```bash
# 构建 Windows 安装包
npm run build:win

# 构建 Mac 安装包
npm run build:mac

# 构建 Linux 安装包
npm run build:linux
```

构建产物输出到 `dist/` 目录。

## 🛠 技术栈

- **Electron 33** — 跨平台桌面框架
- **原生 Node.js 文件系统** — 高效批量文件操作
- **暗色主题** — 保护视力，现代风格

## 📋 系统要求

- Node.js ≥ 18.0.0
- Windows / macOS / Linux

## ⚠️ 注意事项

- 重命名操作会直接修改磁盘上的文件名，操作前请确认预览无误
- 如遇文件名冲突，系统会自动添加序号 `_(数字)` 避免覆盖
- 撤销功能仅能撤销**最近一次**批量操作
