# 足彩14场胜负彩分析规则手册

> 数据来源：国家体育总局体育彩票管理中心 webapi.sporttery.cn
> 适用玩法：传统足彩胜负游戏（14场）
> 更新频率：每期开奖后

---

## 1. 玩法概述

| 项目 | 说明 |
|------|------|
| 竞猜场次 | 14 场足球比赛 |
| 每场结果 | 3（主胜）/ 1（平局）/ 0（客胜） |
| 理论组合数 | 3^14 = 4,782,969 种 |
| 开奖日 | 不固定，取决于赛事安排（通常每周 2-4 期） |
| 数据窗口 | 滚动近 20 期为统计基础 |
| 奖级 | 一等奖（14场全中）、二等奖（中13场） |

---

## 2. 结果代码定义

```
3 = 主队胜 (Home Win)
1 = 平局   (Draw)
0 = 主队负 (Away Win)
```

每期开奖结果为 14 个空格分隔的数字，如：
```
1 3 1 0 0 0 0 3 1 3 0 3 1 1
```

---

## 3. 统计分析维度

### 3.1 胜平负分布

每期统计 3/1/0 各出现次数，正常范围：

| 结果 | 正常范围 | 偏低 | 偏高 |
|------|---------|------|------|
| 主胜(3) | 5-8 场 | <5 | >8 |
| 平局(1) | 2-5 场 | <2 | >5 |
| 客胜(0) | 3-6 场 | <3 | >6 |

> 极端分布（某一结果≥9场 或 某一结果≤1场）标记为异常期。

### 3.2 位置热度矩阵

14 个位置各统计近 20 期 3/1/0 的频次。

| 热度等级 | 条件 | 说明 |
|---------|------|------|
| 🔥 热门结果 | 占比 ≥60% (≥12/20) | 该位置高度倾向于某结果 |
| ● 常态 | 占比 40-55% (8-11/20) | 正常波动范围 |
| ❄️ 冷门结果 | 占比 ≤15% (≤3/20) | 极少出现的结果 |
| ⚠ 分散位置 | 三种结果各 ≥25% | 最难预测的位置 |

### 3.3 奖金冷热度

| 类型 | 判定条件 | 含义 |
|------|---------|------|
| 🍲 火锅奖 | 一等奖≥100注 且 单注<10万 | 结果正路，多数人猜中 |
| 🧊 冷门期 | 一等奖≤5注 或 无人中 | 多场爆冷，难度极高 |
| 🥶 极端冷门 | 一等奖 0 注 | 14场无人全中 |
| ● 正常期 | 其余情况 | 常规难度 |

---

## 4. 难度评估模型

### 4.1 评分体系（满分 10，越高越难）

| 维度 | 权重 | 指标 | 高分条件 |
|------|------|------|---------|
| 平局因子 | 30% | 近20期平均平局率 | 平局率越高越难 |
| 奖金波动 | 25% | 一等奖奖金变异系数 | 波动越大越不稳定 |
| 命中难度 | 25% | 一等奖平均注数 | 注数越少越难 |
| 结果熵值 | 20% | 14位置平均信息熵 | 熵值越高越分散 |

### 4.2 难度等级映射

| 评分范围 | 难度等级 | 标签 |
|---------|---------|------|
| 0.0 - 2.5 | 低 | 🟢 正路 |
| 2.5 - 4.5 | 中低 | 🟡 偏易 |
| 4.5 - 6.0 | 中等 | 🟠 常规 |
| 6.0 - 7.5 | 中高 | 🔴 偏难 |
| 7.5 - 10.0 | 高 | 💀 高难 |

---

## 5. 位置风险标注

对每个场次位置标注风险等级：

| 风险等级 | 条件 | 建议 |
|---------|------|------|
| 🟢 低风险 | 单位置某结果 ≥12/20 | 该位置倾向明确 |
| 🟡 中风险 | 单位置某结果 8-11/20 | 有一定倾向但需留意 |
| 🔴 高风险 | 三种结果各 ≥5/20 | 高度分散，难以判断 |
| ⚠ 平局陷阱 | 平局占比 ≥25% | 需重点评估防平 |

## 6. 数据获取

### API 地址

```
https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry
  ?gameNo=90
  &provinceId=0
  &pageSize=30
  &isDetails=1
  &pageNo=1
```

> gameNo 90 = 胜负游戏（14场胜负彩）

### 返回字段

```json
{
  "success": true,
  "value": {
    "total": 3295,
    "list": [{
      "lotteryGameName": "胜负游戏",
      "lotteryDrawNum": "26096",
      "lotteryDrawResult": "1 3 1 0 0 0 0 3 1 3 0 3 1 1",
      "lotteryDrawTime": "2026-07-27",
      "totalSaleAmount": "16,054,572",
      "prizeLevelList": [
        {"prizeLevel": "一等奖", "stakeCount": "0", "stakeAmount": "0"},
        {"prizeLevel": "二等奖", "stakeCount": "11", "stakeAmount": "280,225"}
      ],
      "matchList": [
        {
          "matchNum": 1,
          "matchName": "瑞超",
          "startTime": "2026-07-26",
          "masterTeamName": "布鲁马",
          "guestTeamName": "哈马比",
          "result": "1",
          "czScore": "1:1"
        }
      ]
    }]
  }
}
```

**关键字段说明**：
- `lotteryDrawResult`：空格分隔的 14 个结果，分别对应 14 场比赛
- `lotteryDrawNum`：期号（如 "26096" = 2026 年第 096 期）
- `prizeLevelList[0]`：一等奖信息；`prizeLevelList[1]`：二等奖信息
- `matchList`：对阵详情（每场比赛的联赛、主客队、比分等）
- `totalSaleAmount`：当期销售总额（含千分位逗号）
- `*`：表示比赛延期/取消，该场结果无效

---

## 7. 速度、并发约束

- API 为 HTTP 明文，无认证要求
- 单次请求约 80KB 数据量，解析时间 < 1s
- 建议缓存当次会话结果，避免重复请求
