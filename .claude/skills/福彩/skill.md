# 双色球分区冷热分析 & 选号生成器

## 触发条件

当用户提出以下任一需求时调用此 Skill：
- 分析双色球数据
- 查询双色球开奖号码
- 生成双色球选号
- 冷热号分析
- 福彩号码推荐
- 提到"双色球"、"福彩"、"红球蓝球"等关键词

## 核心能力

1. **数据获取**：自动从中国福利彩票官网 (cwl.gov.cn) API 拉取最新开奖数据
2. **前区分区**：按 01-10 / 11-20 / 21-33 三区拆分，输出各区冷热频次
3. **后区约束**：蓝球冷热划分 + 两码和值 9-16 规则校验
4. **选号生成**：基于分区热号胆码 + 连号规律 + 冷热配比生成 2 组 7+2 号码

## 执行步骤

### Step 1: 获取原始数据

```bash
curl -s -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" \
  -H "Referer: https://www.cwl.gov.cn/ygkj/wqkjgg/ssq/" \
  --connect-timeout 10 --max-time 30 \
  "https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice?name=ssq&issueCount=30&pageNo=1&pageSize=30"
```

解析返回的 JSON，取最近 20 期数据（`result` 数组前 20 项）。
每期字段：`code`(期号), `red`(红球,逗号分隔), `blue`(蓝球), `date`(日期)。

### Step 2: 运行分析引擎

使用项目下的 `references/ssq_analyzer.js` 脚本对数据进行完整分析。
将获取到的 20 期数据注入脚本顶部的 `draws` 数组，执行 `node` 命令。

### Step 3: 输出格式

必须包含以下四个章节：

**一、前区分区校验**
- 逐期展示近 20 期每期三区分布 (一区 01-10 / 二区 11-20 / 三区 21-33)
- 标注是否三区全覆盖（缺区标红警示）
- 输出各区热号(≥5次)、温号(3-4次)、冷号(≤2次)明细

**二、后区冷热划分 & 两码和值约束**
- 蓝球 1-16 频次表，分为 HOT(≥3次) / WARM(2次) / COLD(1次) / ICE(0次) 四级
- 列出符合"两码和值 9-16 + 非全热 + 非全冷"的两码组合
- 标注代表性搭配模式

**三、选号约束条件**
- 连号规律：近 20 期连号出现率及高频连号对
- 各区胆码候选（按频次 + 活跃度排序取前 3）
- 区间分布约束说明

**四、成品号码 (2 组)**
- 每组含 7 个红球 + 2 个蓝球
- 附带分区码数比 (如 2-3-2)、连号标注、冷热标签
- 后区两码和值逐一校验
- 最终汇总表格

## 关键规则（不可违反）

### 前区规则
| 规则 | 说明 |
|------|------|
| 三区定义 | 一区 01-10, 二区 11-20, 三区 21-33 |
| 全覆盖 | 每 7 码必须含三区各至少 1 码 |
| 不扎堆 | 单区最多 3 码，最少 1 码 |
| 热号主导 | 热号(WARM+HOT) ≥ 5 个 (7 码中) |
| 连号加持 | 每组至少含 1 组连号 (差=1) 或跳连 (差=2) |

### 后区规则
| 规则 | 说明 |
|------|------|
| 冷热阈值 | ≥3次=HOT, 2次=WARM, 1次=COLD, 0次=ICE |
| 和值范围 | 任取两码之和 ∈ [9, 16] |
| 禁止全热 | 两码不能全为 HOT |
| 禁止全冷 | 两码不能全为 COLD/ICE |
| 搭配要求 | 必须混合 ≥2 个热度等级 |

### 冷热判定阈值
| 等级 | 前区(红球) | 后区(蓝球) |
|------|-----------|-----------|
| 🔥 热号 | 出现 ≥5 次 | 出现 ≥3 次 |
| ● 温号 | 出现 3-4 次 | 出现 2 次 |
| ❄️ 冷号 | 出现 1-2 次 | 出现 1 次 |
| 🧊 极冷 | 出现 0 次 | 出现 0 次 |

## 注意事项

- 数据源为 `cwl.gov.cn` 官方 API（中国福利彩票发行管理中心）
- 每次调用必须重新拉取数据，确保使用最新开奖结果
- 双色球每周二、四、日开奖
- 输出末尾必须附免责声明：不构成投注建议，彩票为独立随机事件
- 分析结论为历史统计推演，历史频率不代表未来概率
